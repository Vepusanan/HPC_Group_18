Zero Boundary Handling

Cells outside the N×N boundary are treated as dead (zero-padded). Both CPU and CUDA versions match this condition without wraparound.

Coalesced Memory Access

16×16 blocks group consecutive threadIdx.x threads over adjacent columns in row-major layout, ensuring 100% coalesced DRAM transactions.

Zero-Copy Pointer Swapping

Generations swap device pointers d_current and d_next on the host in O(1) time without copying memory over PCIe.

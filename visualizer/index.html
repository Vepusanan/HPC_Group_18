    Generation 0

    How the implementations work

    CPU / sequential loops

    One host thread traverses rows and columns in contiguous system memory. Two buffers preserve simultaneous updates; pointer swaps avoid grid copies. The compiler may vectorize work.

    CUDA / parallel cells

    Each valid CUDA thread updates one cell. 16 × 16 blocks access device memory. Both buffers stay on the GPU for all 100 launches. Blocks and warps are scheduled over the available GPU hardware.
